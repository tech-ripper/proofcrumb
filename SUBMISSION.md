**Short description**

ProofCrumb turns completed work and its public deliverable into a tamper-evident Cookie Chain receipt. Users connect Nightly, enter a public-safe task description and HTTPS deliverable, approve one low-cost memo transaction, receive real-time confirmation, and revisit the permanent proof through CookieScan.

**Long submission description**

ProofCrumb is an open-source proof-of-delivery application built for Cookie Chain. It gives freelancers, DAOs, distributed teams, and autonomous agents a lightweight way to prove that public work was completed and linked at a specific time without operating an account database or uploading private files.

The application supports Nightly through Wallet Standard, displays the connected address, validates public inputs, checks native COOK balance and fees against the Cookie Chain RPC, requests wallet signing, broadcasts the signed transaction explicitly through Cookie Chain, confirms finality, and discovers the signer's prior ProofCrumb receipts. Every receipt uses the versioned `PROOFCRUMB:v1` memo format and links directly to CookieScan.

The included production transaction demonstrates the full flow on Cookie Chain with a finalized `0.000005 COOK` fee.
